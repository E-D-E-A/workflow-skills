Three values cross the host boundary

  • config — a JSON string with the API URL, topic and optional display settings.
  • websocket — the original host object with subscribe and unsubscribe.
  • normalizeMessage — a function that returns { id, connectionStatus } or null.
Only config is serialized. Objects and functions must arrive as JavaScript element properties. All three are captured once on mount.

Two data paths meet in Vue state

REST → fetch the complete metadata array, validate it, and initialize the list.

WebSocket → normalize one message, validate it, and update the row with that ID.

Subscribe happens before the GET. Updates received before metadata is available are buffered and applied over the REST result.

Federation loading and data loading are separate. The host can report READY while the remote is still fetching interfaces.

Replace for another feature

The interfaces contract, REST endpoint, normalizer, buffering and collection UI. A different MFE does not automatically need WebSocket support.

No new router, global store, per-row subscription, or WebSocket connection is part of this package.

What remains specific to your internal system?

The actual REST endpoint, authentication, status labels/colors, and the private generic-host property/event bridge. The public runtime and standalone remote were tested; the private host examples are integration sketches.
