External interfaces MFE · 3-minute read

From host to live status.

One remote owns the collection, fetches metadata and uses one subscription on the host’s existing WebSocket manager.

Host → Mount → Load → Update → Render → Unmount
01Host

Pass the three inputs

The host loads ExternalInterfaces/register and renders one collection. Config is JSON; the WebSocket manager and normalizer are live properties.

examples/host/registry.ts
const serializedConfig = JSON.stringify(config);
const elementProperties = {
  config: serializedConfig,
  websocket,
  normalizeMessage,
};
return elementProperties;

One MFE contains the full list. The navbar does not subscribe.

02Mount

Validate and capture once

initializeInterfaces validates the inputs with Zod and starts loading. Later config changes require a remount.

src/ExternalInterfaces.vue
mountedInputs = parseInputs(
  props.config,
  props.websocket,
  props.normalizeMessage,
);
configuration.value = mountedInputs.config;
// After successful validation:
void loadInterfaces();

register.ts wraps Vue as cust-external-interfaces and installs its own Vuetify instance.

03Load

Subscribe, then fetch

Save one subscription cleanup function. After subscribing succeeds, fetch and validate the metadata array, then apply it to local state.

ExternalInterfaces.vue → externalInterfacesData.ts
// Inside ensureStatusSubscription:
stopStatusSubscription =
  subscribeToInterfaceStatuses(subscriptionOptions);

// Inside loadInterfaces, after subscribing succeeds:
const fetchedInterfaces =
  await fetchInterfaceMetadata(inputs.config);
// After checking the component is still mounted:
applyInitialInterfaces(fetchedInterfaces);

REST failure keeps the listener. Retry repeats the GET using the same inputs and subscription.

04Update

Normalize, then match the ID

The supplied normalizer returns { id, connectionStatus } or null to ignore. After validation, the component updates the matching row.

src/ExternalInterfaces.vue · applyStatusUpdate
const matchingInterface = interfaces.value.find(
  externalInterface => {
    const hasMatchingId = externalInterface.id === interfaceId;
    return hasMatchingId;
  },
);
if (matchingInterface) {
  matchingInterface.connectionStatus = connectionStatus;
}

Before metadata arrives, updates wait in a Map. Their latest status wins over REST, including null. Unknown IDs do not create rows.

05Render

Prepare the display rows

The explicit callback converts each interface into its label, color and other display values. Vue recomputes these when state changes; the template loops over them.

src/ExternalInterfaces.vue
const interfaceRows = computed(() => {
  const displayRows = interfaces.value.map(externalInterface => {
    const displayRow = createInterfaceRow(externalInterface);
    return displayRow;
  });
  return displayRows;
});

The v-for and Vuetify chips are inside the remote. A chip click sends interfaceId and connectionStatus back to the host.

06Unmount

Remove this listener

Vue calls cleanupInterfaces on unmount. The saved cleanup function calls the original manager’s unsubscribe(topic) and ignores queued callbacks.

src/ExternalInterfaces.vue
function cleanupInterfaces() {
  isUnmounted = true;
  stopStatusSubscription?.();
  stopStatusSubscription = undefined;
  pendingStatusUpdates.clear();
}

The host’s socket stays open. Pending REST requests finish, but late results/errors are ignored. No abort, signal or custom REST timeout.

Federation wiring: remoteEntry.var.js → ./register → cust-external-interfaces. The remote name, host key, entryGlobalName and import prefix are all ExternalInterfaces.
